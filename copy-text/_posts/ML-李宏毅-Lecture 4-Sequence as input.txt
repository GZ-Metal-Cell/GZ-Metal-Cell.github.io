### Sequence Labeling

![png](P1.9.png)

​	利用全连接网络，输入一个句子，输出对应单词数目的标签。当一个句子里出现两个相同的单词，并且它们的词性不同（例如：I saw a saw. 我看见一把锯子），这个时候就需要考虑上下文：利用滑动窗口，每个向量查看窗口中相邻的其他向量的性质。

​	但是这种方法不能解决整条语句的分析问题（固定的滑动窗口难以应用在长度不等的语句上），即语义分析。这就引出了 Self-attention 技术。

![png](P1.10.png)

​	输入整个语句的向量到 self-attention 中，输出对应个数的向量，再将其结果输入到全连接网络，最后输出标签。以上过程可多次重复。

> ​	Transformer 起源于 2017 年的一篇 google brain 的又一篇神文《Attention is all you need》，至此由引领了在 NLP 和 CV 了又一研究热点。
>
> ​	在 Transformer 中一个非常关键的贡献就是 self-attention。就是利用输入样本自身的关系构建注意力模型。

- [[1706.03762\] Attention Is All You Need (arxiv.org)](https://arxiv.org/abs/1706.03762)

![png](P1.11.png)

​	Self-attention 层的上一层可以是输入层，也可以是隐藏层。每个输出 $b$ 都与所有输入 $a$ 相关。

![png](P1.12.png)

​	Self-attention 层的作用就是找到向量集中各个向量中的关联性 $\alpha$。

![png](P1.13.png)

计算关联性 $\alpha$ 的方法：

- **Dot-product** 中使用了 Transformer 的方法。把输入的向量分别乘以不同的矩阵 $W^q$，$W^k$，最后得到关联性 $\alpha=\mathbf{q}\cdot\mathbf{k}$
- **Additive**

Self-attention 中又引入了三个非常重要的元素：**Query**、**Key** 和 **Value**。

​	假设$\mathbf{X}\in\mathbb{R}^{\mathbf{n}\times \mathbf{d}}$ 是一个输入样本序列的特征，其中 $\mathbf{n}$ 是输入样本个数（序列长度），$\mathbf{d}$ 是单个样本维度。

- Query：$\mathbf{Q}=\mathbf{X}\cdot\mathbf{W^Q}$，其中 $\mathbf{W^Q}\in\mathbb{R}^{\mathbf{d\times d_q}}$
- Key：$\mathbf{K}=\mathbf{X}\cdot\mathbf{W^K}$，其中 $\mathbf{W^K}\in\mathbb{R}^{\mathbf{d\times d_K}}$
- Value：$\mathbf{V}=\mathbf{X}\cdot\mathbf{W^V}$，其中 $\mathbf{W^K}\in\mathbb{R}^{\mathbf{d\times d_V}}$

（$\mathbf{X}$ 分别乘上某个矩阵得到 $\mathbf{Q, K, V}$）

![png](P1.14.png)

​	如求向量 $\mathbf{a^1}$ 与向量 $a^{i}$ 的关联性 $\alpha'_{1,i}$。根据 $\mathbf{q^1,k^1}$ 求得某个向量与所有向量关联性 $\alpha_{1,1}$ 后，再用 softmax 函数（Normalization 操作，也可以是其他激活函数，如 ReLU）：

$$\alpha'_{1,i}=\exp(\alpha_{1,i})/\sum_j\exp(\alpha_{1,j})$$

![png](P1.15.png)

​	将所得的 $\alpha'_{1,1}$ 与 由向量本身计算得到的 $\mathbf{v^1}$ 相乘求得 $\mathbf{b^1}=\sum_ia'_{1,i}\mathbf{v^i}$。

​	根据分数（关联性）抽取重要信息。谁的分数（Value）越大，谁就更影响结果。

## 【機器學習 2021】自注意力機制 -Self-attention- -下-

### Self-attention

![png](P2.1.png)

​	Self-attention 层将输入 $a$ 转换为输出 $b$，这个过程是可以并行计算的。 

![png](P2.2.png)

与求 $\mathbf{b^1}=\sum_ia'_{1,i}\mathbf{v^i}$ 相同的方法求得 $\mathbf{b^2}=\sum_ia'_{2,i}\mathbf{v^i}$。

![png](P2.3.png)

​	由于用于得到 $\mathbf{q,k,v}$ 所乘的矩阵 $W^q,W^k,W^v$ 都相同，所以可以将所有 $\mathbf{a}$ 合并成一个矩阵 $I$，通过一次矩阵运算得到所有的 $\mathbf{q,k,v}$，分别合并称为 $Q,K,V$。

![png](P2.4.png)

​	通过线性代数知识，$A=K^TQ$。$A'=softmax(A)$。

![png](P2.5.png)

​	通过线性代数知识，$O=VA'$，$O$ 就是 self-attention 层的输出。

![png](P2.6.png)

​	$W^q,W^k,W^v$ 这些参数的值要通过学习得到。

上述过程可总结为：

- 输入矩阵 $I$ 分别乘以三个 $W$ 得到三个矩阵 $Q,K,V$
- 使 $A=QK^T$，经过处理的到注意力矩阵 $A'=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)$
- 输出 $O=A'V$，即 $Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$，其中，$\sqrt{d_k}$ 为向量的长度。

### Multi-head Self-attention

![png](P2.7.png)



​	Multi-head Self-attention 是 Self-attention 的变种。考虑不同类型的相关性。计算完 $\mathbf{q,k,v}$ 后，再乘上 head 数的矩阵，得到更多分支。

![png](P2.8.png)

​	这样得到的输出会有多个向量。最后再乘一个 $W^O$ 矩阵得到最终的输出 $\mathbf b$。

### Positional Encoding

![png](P2.9.png)

​	Self-attention 机制没有考虑向量的位置信息。解决办法是在输入向量 $\mathbf{a^i}$ 中额外添加位置信息 $\mathbf{e^i}$。位置信息 $\mathbf{e^i}$ 的表示形式可以是：

- 人为设定
- 从数据中学习

![png](P2.10.png)

​	论文[[2003.09229\] Learning to Encode Position for Transformer with Continuous Dynamical Model (arxiv.org)](https://arxiv.org/abs/2003.09229) 阐述了各种模型得到的位置信息的表现形式。

### Long Short-term Memory (LSTM)

![png](E1.13.png)

LSTM 是一种特殊的神经网络结构，拥有 4 个输入，1 个输出。

![png](E1.8.png)

输入：

- 通常的输入 $z$
- 由信号控制的 Input Gate，输入信号 $z_i$
- 由信号控制的 Forget Gate，输入信号 $z_f$
- 由信号控制的 Output Gate，输入信号 $z_o$

输入和门都会有一个激活函数（一般是 Sigmoid，便于将值取 0-1 之间，ReLU 在此性能较差）

经过 Forget Gate 后的值 $c'=g(z)f(z_i)+cf(z_f)$，因此 Forget Gate 中的 $c$ 取 1 时 Memory 不遗忘，取 0 时 Memory 遗忘。

最后的输出值 $a=h(c')f(z_o)$。

![png](E1.14.png)

​	举例，假设这个模型真实的情景是：

- 当 $x_2=1$ 时，把 $x_1$ 的值加到 memory 中。
- 当 $x_2=-1$ 时，重置 memory 的值（设为 0）。
- 当 $x_3=1$ 时，将 memory 的值作为输出值。

![png](E1.15.png)

​	使用一个 LSTM 神经元可以拟合出这样的函数（假设 w 值已经被训练好）。

![png](E1.16.png)

​	因此 LSTM 的参数量是普通神经元的 4 倍。

![png](E1.17.png)

​	把输入向量 $x^t$ 拆分成 4 个向量 $z^f,z^i,z,z^c$ 看。

![png](E1.18.png)

​	向量在 LSTM 中的示意图。

![png](E1.19.png)

​	LSTM 神经元可以有很多个。

![png](E1.20.png)

​	还可以把 memory 中的值 $c^{t-1}$ 和

​	上次的输出值 $h^{t-1}$（称之为“peephole”）放到输入序列中。

![png](E1.21.png)

​	多层，多个的 LSTM。

![png](E1.22.png)

​	Keras 可以很好地实现它。

​	一般来说 RNN 就是指 LSTM。

​	Keras 支持 LSTM，GRU（比 LSTM 少一个门，据说性能与 LSTM 相当，而较少的参数量可以防止过拟合？），以及课程开始讲的最传统的 SimpleRNN。

![png](E2.4.png)

​	Razvan Pascanu (ICML’13) 的研究，RNN 的参数对应的损失函数是很陡峭的，因此难以训练。提出解决方案：引入 Clipping——当 gradient 大于某个数值时，就等于某个数值。

![png](E2.5.png)

​	RNN 在不同时间内反复使用同样的东西，导致梯度爆炸（如 $w$ 都取 $1.01$ 时，第 $1000$ 层的输出极大）或梯度消失（如 $w$ 都取 $1.01$ 时，第 $1000$ 层的输出约等于 $0$）。

![png](E2.6.png)

​	LSTM 可以解决梯度消失的问题，但是难以解决梯度爆炸的问题。

- Memory and input are added
- The influence never disappears unless forget gate is closed

​	GRU 是更简单版本的 LSTM：

- 相比于 LSTM，少了一个门（参数）
- 当 input gate 打开时，forget gate 就自动关闭

![png](E2.7.png)

​	其他 LSTM 的变形：`Clockwise RNN`、`Structurally Constrained Recurrent Network(SCRN)`

- Vanilla RNN Initialized with Identity matrix + ReLU activation function <font color="#136ec2">[Quoc V. Le, arXiv’15]</font>

### Spatial-based Convolution

![png](E3.16.png)

Terminology：术语

- Aggregate：用 neighbor feature update 下一层（Layer i + 1）的 hidden state

- Readout：把所有 nodes 的 feature 集合起来代表整个 graph（类似 LSTM 把整个句子向量压缩为一个向量）

#### NN4G

![png](E3.17.png)

- [Neural Network for Graphs: A Contextual Constructive Approach | IEEE Journals & Magazine | IEEE Xplore](https://ieeexplore.ieee.org/document/4773279)

$h^{layer}_{node}$：第 layer 层 第 node 个节点。

$$h^1_3=\hat w_{1,0}\left(h^0_0+h^0_2+h^0_4\right)+\bar w_1\cdot x_3$$

​	Input layer 经过 embedding（如 $h^0_3=\bar w_0\cdot x_3$）之后到 Hidden layer 0。将其相邻的节点 ($h^0_0+h^0_2+h^0_4$) 相加然后乘以权重（$\hat w_{1,0}$）再加上之前 Input layer 的原始输入 ($\hat w_1\cdot x_3$) 用于得到新的参数 ($h^1_3$)。

​	关于为什么要相加的问题：如果不用相加的话，你就很难去处理节点间邻居数量不同这个巨大的区别。另外，相加是最简单也是被证实最有效的利用邻点信息的方法。

![png](E3.18.png)

​	整个图的表示是通过求出每一层整个图中的顶点间的特征均值，然后各自乘以相应的权重再把每一层得到的结果相加得到整个 graph 的 feature $y$。

#### DCNN

![png](E3.19.png)

- [[1511.02136\] Diffusion-Convolutional Neural Networks (arxiv.org)](https://arxiv.org/abs/1511.02136)

每一层的更新方式：

​	如第一层，更新某个节点首先找到与它距离为 1 的节点（也就是邻居节点, $d(3,\cdot)=1$），然后用原始的输入相加取平均值 ($MEAN()$) 再乘以权重 ($w^0_3$)。$h^0_3=w^0_3MEAN(d(3,\cdot))=1$

​	第二层，更新更新某个节点首先找到与它距离为 2 的节点（这样也包括了它自自己本身），然后用原始的输入相加取平均值再乘以权重。$h^1_3=w^1_3MEAN(d(3,\cdot))=2$

![png](E3.20.png)

​	这样就可以将每一层的节点特征组成一个矩阵，然后叠在一起。

​	将某个节点的 $\{h^0_1,h^1_1,...h^k_1\}$ 乘上某个权重 $W$，得到特征 $y_1$。

#### DGC

![png](E3.31.png)

- [[1707.01926\] Diffusion Convolutional Recurrent Neural Network: Data-Driven Traffic Forecasting (arxiv.org)](https://arxiv.org/abs/1707.01926)

​	与 DCNN 中 Readout 过程不同，将 $H^0,H^1,...H^K$ 加起来。

#### MoNET

![png](E3.21.png)

- [[1611.08402\] Geometric deep learning on graphs and manifolds using mixture model CNNs (arxiv.org)](https://arxiv.org/abs/1611.08402)

​	上面两个方法在处理节点和节点之间的关系的时候都是用加法，其实忽略节点之间如果边有**权重**，这样是不合理的，因此这个方法就是用来解决不同权重边的方法。

​	引入权重 $\mathbf u$ 定义某个节点与某个节点之间的距离。

$$\mathbf{u}(x,y)=\left(\frac{1}{\sqrt{deg(x)}},\frac{1}{\sqrt{deg(y)}}\right)^T$$

​	其中的 deg 表示的是节点的度。无向图当中也就是说有几个和它相连接的节点。这里定义的距离公式可以有不同的。也就是给每个节点不同的权重 weighted sum。

$$h^1_3=w(\hat u_{3,0})\times h^0_0+=w(\hat u_{3,2})\times h^0_2\times h^0_4$$

​	$w$ 由神经网络得到，$\hat u$ 由 $\mathbf u$ 变换而来。
