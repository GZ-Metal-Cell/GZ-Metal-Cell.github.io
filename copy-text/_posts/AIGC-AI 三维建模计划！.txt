# 正文

​	从 [ahujasid/blender-mcp: Open-source MCP to use Blender with any LLM](https://github.com/ahujasid/blender-mcp) 下载源码。

​	Blender 中 `Preferences` - `Add-ons` - `Install from Disk...` 选择 blender-mcp 项目中的 `addon.py`。

![webp](1.webp)

​	在视口右侧菜单下 `Connect to MCP Server`，打开 Agent 控制 Blender 的渠道。

![webp](2.webp)

​	按照 `Readme.md` 所说，Agent 侧 MCP 配置方法如下：

```json
{
    "mcpServers": {
        "blender": {
            "command": "uvx",
            "args": ["--python", "3.11", "blender-mcp"],
            "env": { "UV_PYTHON_PREFERENCE": "only-managed" }
        }
    }
}
```

​	命令行看下是否能连：

```shell
uvx --python 3.11 blender-mcp
```

![webp](3.webp)

​	在 Agent 侧配置 MCP：

![webp](4.webp)

​	让 Agent 使用 MCP：

```
帮我在Blender中创建随机大小的若干球体
```

![webp](5.webp)

​	上面很快就完成了。整些复杂的：

```
用 Blender 创建一个 Low-Poly 风格的室内三维场景，要求有足够的家具（床、书桌等）和装饰物。
```
