# 正文

| 特性             | DeepWiki                             | Zread                                  |
| ---------------- | ------------------------------------ | -------------------------------------- |
| **主要功能**     | 自动生成代码仓库文档，提供交互式问答 | 构建和维护团队内部知识库，支持文档协作 |
| **适用对象**     | 开发者、技术团队                     | 企业团队、产品经理、技术写作者         |
| **部署方式**     | 提供在线版和开源版本，可本地部署     | 提供 SaaS 服务，支持企业级部署         |
| **AI 支持**      | 支持多种 AI 模型，提供智能问答功能   | 暂无 AI 驱动的文档生成                 |
| **私有仓库支持** | 支持，通过访问令牌分析私有仓库       | 不适用                                 |

**DeepWiki**

- ==**方式**：把 GitHub 仓库 URL 的 `github` 改成 `deepwiki`==
- **功能**：自动生成文档、架构图、依赖关系，并支持 AI 问答
- **限制**：仅支持公开仓库，私有仓库需自托管版本

**Zread**

- **方式**：登录 Zread，选择“导入仓库”，粘贴 GitHub URL
- **功能**：导入 README 或 Markdown 文档，构建团队知识库
- **限制**：不会自动生成代码结构图或 AI 问答，更适合协作管理

**总结**：

- **DeepWiki** → 快速生成代码文档、智能问答
- **Zread** → 团队协作与知识库管理
