# 正文

## OCPP 1.6J 介绍

**OCPP（Open Charge Point Protocol）** 是一种用于 **电动汽车充电桩（Charge Point）** 与 **充电管理系统（Central System / CSMS）** 之间通信的开放协议。

它定义了消息格式、通信流程、命令集，使不同厂家的设备能够互联互通。

```mermaid
sequenceDiagram
    autonumber
    participant CP as Charge Point（客户端）
    participant CS as Central System（服务器）

    Note over CP,CS: 🔌 启动阶段
    CP->>CS: BootNotification<br/>（包含厂商、型号、序列号）
    CS-->>CP: BootNotification.Conf<br/>（注册状态 + 心跳间隔）

    loop 每隔心跳间隔
        CP->>CS: Heartbeat<br/>（保持连接）
        CS-->>CP: Heartbeat.Conf<br/>（返回当前时间）
    end

    Note over CP,CS: 🟢 准备充电
    CP->>CS: StatusNotification<br/>（状态：Available）

    Note over CP,CS: 💳 用户刷卡
    CP->>CS: Authorize<br/>（发送RFID标签）
    CS-->>CP: Authorize.Conf<br/>（返回授权状态）

    Note over CP,CS: ⚡ 开始充电
    CP->>CS: StartTransaction<br/>（connectorId、meterStart、idTag）
    CS-->>CP: StartTransaction.Conf<br/>（transactionId）

    loop 充电过程中
        CP->>CS: MeterValues<br/>（电压、电流、功率等）
        CP->>CS: StatusNotification<br/>（状态：Charging）
    end

    Note over CP,CS: 🟥 停止充电
    CP->>CS: StopTransaction<br/>（transactionId、meterStop、timestamp）
    CS-->>CP: StopTransaction.Conf<br/>（最终授权状态）

    Note over CP,CS: 🧭 结束后状态
    CP->>CS: StatusNotification<br/>（状态：Available）

    Note over CS: 🧩 管理系统可随时下发命令
    CS-->>CP: RemoteStartTransaction / RemoteStopTransaction / UpdateFirmware / TriggerMessage 等

```

典型的充电流程如下：

> `BootNotification` 注册 → `StatusNotification` 报告可用 → `Authorize` 验证用户 → `StartTransaction` 开始充电 → `MeterValues` 上报数据 → `StopTransaction` 结束充电

## Steve 服务端

### 快速部署

​	Steve 基于 Java、MySQL（XMAPP） 和 Maven。安装之。

​	Docker 的操作了老半天，没成功😅。老老实实手动配置。

建立数据库：

```mysql
CREATE DATABASE stevedb CHARACTER SET utf8 COLLATE utf8_unicode_ci;  
CREATE USER 'steve'@'localhost' IDENTIFIED BY 'changeme';  
GRANT ALL PRIVILEGES ON stevedb.* TO 'steve'@'localhost';
```

设置 MySQL 时区与 Java 一致：

```sql
USE stevedb;
SET GLOBAL time_zone = '+00:00';
SET time_zone = '+00:00';
```

上述语句执行后，确保下述查询语句返回结果为 `+00:00`：

```sql
SELECT @@global.time_zone, @@session.time_zone;
```

## Python 客户端

使用 uv 构建一个客户端项目：

```shell
uv init
uv add websockets
uv add ocpp
```

然后来一段客户端代码：

```python
import asyncio
import logging
import websockets
from datetime import datetime, timezone
from ocpp.v16 import ChargePoint as cp
from ocpp.v16 import call, call_result
from ocpp.v16.enums import Action, RemoteStartStopStatus
from ocpp.routing import on

logging.basicConfig(level=logging.INFO)


class ChargePoint(cp):
    def __init__(self, id, connection):
        super().__init__(id, connection)
        self.transaction_id = None
        self._running = True  # 控制心跳循环

    @on(Action.remote_start_transaction)
    async def on_remote_start_transaction(self, id_tag, connector_id=None, **kwargs):
        print(f"收到远程启动命令: id_tag={id_tag}")
        await self.start_transaction(id_tag, connector_id or 1)
        return call_result.RemoteStartTransaction(
            status=RemoteStartStopStatus.accepted
        )

    async def send_boot_notification(self):
        request = call.BootNotification(
            charge_point_model="PythonClient",
            charge_point_vendor="GPT-Lab"
        )
        response = await self.call(request)
        print(f"BootNotification response: {response}")
        return response

    async def send_heartbeat_periodically(self, interval=60):
        while self._running:
            try:
                request = call.Heartbeat()
                response = await self.call(request)
                print(f"Heartbeat at {response.current_time}")
            except asyncio.CancelledError:
                break
            except Exception as e:
                print(f"Heartbeat error: {e}")
            await asyncio.sleep(interval)

    async def authorize(self, id_tag):
        request = call.Authorize(id_tag=id_tag)
        response = await self.call(request)
        print(f"Authorize response: {response}")
        return response

    async def start_transaction(self, id_tag, connector_id=1):
        request = call.StartTransaction(
            connector_id=connector_id,
            id_tag=id_tag,
            meter_start=0,
            timestamp=datetime.now(timezone.utc).isoformat()
        )
        response = await self.call(request)
        self.transaction_id = response.transaction_id
        print(f"StartTransaction response: transaction_id={self.transaction_id}")
        return response

    async def stop_transaction(self, meter_stop=100):
        if not self.transaction_id:
            print("没有活动的充电事务")
            return

        request = call.StopTransaction(
            meter_stop=meter_stop,
            timestamp=datetime.now(timezone.utc).isoformat(),
            transaction_id=self.transaction_id
        )
        response = await self.call(request)
        print(f"StopTransaction response: {response}")
        self.transaction_id = None
        return response

    async def user_input_loop(self):
        print("\n可用命令:")
        print("1. authorize <id_tag> - 授权")
        print("2. start <id_tag> [connector_id] - 开始充电")
        print("3. stop [meter_stop] - 停止充电")
        print("4. quit - 退出")

        while True:
            try:
                user_input = await asyncio.get_event_loop().run_in_executor(
                    None, input, "\n请输入命令: "
                )
                parts = user_input.strip().split()
                if not parts:
                    continue

                command = parts[0].lower()

                if command == "authorize":
                    if len(parts) < 2:
                        print("用法: authorize <id_tag>")
                        continue
                    id_tag = parts[1]
                    await self.authorize(id_tag)

                elif command == "start":
                    if len(parts) < 2:
                        print("用法: start <id_tag> [connector_id]")
                        continue
                    id_tag = parts[1]
                    connector_id = int(parts[2]) if len(parts) > 2 else 1
                    await self.start_transaction(id_tag, connector_id)

                elif command == "stop":
                    meter_stop = int(parts[1]) if len(parts) > 1 else 100
                    await self.stop_transaction(meter_stop)

                elif command == "quit":
                    print("退出程序...")
                    self._running = False
                    break

                else:
                    print(f"未知命令: {command}")

            except Exception as e:
                print(f"错误: {e}")


async def main():
    url = "ws://localhost:8080/steve/websocket/CentralSystemService/CP01"
    async with websockets.connect(url, subprotocols=["ocpp1.6"]) as ws:
        cp_client = ChargePoint("CP01", ws)

        heartbeat_task = asyncio.create_task(cp_client.send_heartbeat_periodically(30))
        start_task = asyncio.create_task(cp_client.start())
        boot_task = asyncio.create_task(cp_client.send_boot_notification())
        user_input_task = asyncio.create_task(cp_client.user_input_loop())

        # 等待用户退出
        await user_input_task

        # 停止其他任务
        for task in [heartbeat_task, start_task, boot_task]:
            task.cancel()
            try:
                await task
            except asyncio.CancelledError:
                pass


if __name__ == "__main__":
    asyncio.run(main())

```
