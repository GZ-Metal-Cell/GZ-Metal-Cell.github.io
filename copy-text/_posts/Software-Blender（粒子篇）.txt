# 课程

## 4

### 【粒子篇】4.1 发射体粒子

![png](4.1_1.png)

​	给物体增加粒子系统，emmm 跟 Unity 里异曲同工吧。

​	粒子系统有两种：

- 发射体粒子

- 毛发粒子

![png](4.1_2.png)

​	给物体添加碰撞属性可以使得生成的粒子接触到物体时发生碰撞效果。

![png](4.1_3.png)

​	可以新建立场以改变粒子系统的移动轨迹。

![png](4.1_4.png)

​	Scene 设置里可以改变重力属性。

### 【粒子篇】4.2 毛发粒子

![png](4.2_1.png)

​	粒子系统选择毛发，其默认材质会跟物体原来材质相同。

![png](4.2_2.png)

​	“毛发”也可以是物体。

![png](4.2_3.png)

​	旋转物体使得毛发位置正常。

![png](4.2_4.png)

​	将“毛发”放置在山丘上。

![png](4.2_5.png)

​	“毛发”可以是一个组里的所有物体。

![png](4.2_6.png)

​	利用毛发粒子系统生成的花圃。

![png](4.2_7.png)

​	Object Info 节点连接 ColorRamp 节点，可以使得材质的颜色随机化。

### 【粒子篇】4.3 本章练习-火焰粒子

- [youtube.com/@blenderforbeg](https://www.youtube.com/@blenderforbeg)
- [SouthernShotty - YouTube](https://www.youtube.com/@SouthernShotty)

![png](4.3_1.png)

​	建个立方体，2 等级的表面细分，利用衰减编辑往上拉得到火苗的模型。

![png](4.3_2.png)

​	选中顶端的顶点，设为顶点组。

![png](4.3_3.png)

​	再 Weight Paint 中，修改模型顶点的权重。

![png](4.3_4.png)

​	使用 Smooth Vertex Weights 修改得到的火焰模型权重。

![png](4.3_5.png)

​	使用 Displace 修改器，绑定一个空对象，达到火苗燃烧时形变的效果。

![png](4.3_6.png)

​	对于这个空对象，设置 Z 值为 `frame/10`，这样这个空对象就会随时间轴沿 Z 轴方向向上移动。

![png](4.3_7.png)

​	木材模型，一个圆柱体，中间 `I + E` 向里挤出两个面。

![png](4.3_8.png)

​	给大火苗一个渐变材质，Texture Coordinate 选择 Object 以绕开 UV 贴图。

![png](4.3_9.png)

​	小火苗换个深点的颜色。

![png](4.3_10.png)

​	木材使用的材质。

![png](4.3_11.png)

​	再整个粒子系统。
