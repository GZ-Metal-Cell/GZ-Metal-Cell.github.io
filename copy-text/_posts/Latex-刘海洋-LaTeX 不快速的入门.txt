## 第一部分 组织文档结构

### 文档由什么组成?

- 标题
- 前言/摘要
- 目录
- 正文
  - 篇、章、小节、小段
    - 文字、公式
    - 列表：编号的、不编号的、带小标题的
    - 定理、引理、命题、证明、结论
    - 诗歌、引文、程序代码、算法伪码
    - 制表
    - 画图
- 文献
- 索引、词汇表

### 纲举目张

$\LaTeX$支持<font color="red">结构化</font>的文档编写方式，步骤：

- 拟定主题
- 列出提纲
- 填写内容
- ~~调整格式~~不要在意格式

### 其他软件

- markdown
- LYX：结构化的文档写作系统

### LATEX 文档基本结构

```latex
%%% 简单文档
% 导言：格式设置
\documentclass{ctexart}
\usepackage[b5paper]{geometry}
% 正文：填写内容
\begin{document}
使用 \LaTeX
\end{document}
```

以<font color="#136ec2">document</font>环境为界，

- <font color="#136ec2">document</font>环境前是导言部分(preamble);

- 环境内部是正文部分；

- 环境之后的部分被忽略

在导言区进行格式设置，正文部分套用格式。

### 文档部件

- 标题：<font color="#136ec2">\title</font>、<font color="#136ec2">\author</font>、<font color="#136ec2">\date</font>——<font color="#136ec2">\maketitle</font>
- 摘要/前言：<font color="#136ec2">abstract</font>环境/<font color="#136ec2">\chapter*</font>
- 目录：<font color="#136ec2">\tableofcontents</font>
- 章节：<font color="#136ec2">\chapter</font>、<font color="#136ec2">\section</font>...
- 附录：<font color="#136ec2">\appendix</font>+<font color="#136ec2">\chapter</font>或<font color="#136ec2">\section</font>...
- 文献：<font color="#136ec2">\bibliography</font>
- 索引：<font color="#136ec2">\printindex</font>

### 文档划分

- 大型文档：
  - <font color="#136ec2">\frontmatter</font>
  - <font color="#136ec2">\mainmatter</font>
  - <font color="#136ec2">\backmatter</font>
- 一般文档：
  - <font color="#136ec2">\appendix</font>

| 层次 | 名称          | 命令                                     | 说明                                                         |
| ---- | ------------- | ---------------------------------------- | ------------------------------------------------------------ |
| -1   | part          | <font color="#136ec2">\part</font>          | 可选的最高层                                                 |
| 0    | chapter       | <font color="#136ec2">\chapter</font>       | <font color="#136ec2">report</font>，<font color="#136ec2">book</font>类最高层：<font color="red">书</font> |
| 1    | section       | <font color="#136ec2">\section</font>       | <font color="#136ec2">article</font>类最高层：<font color="red">学生论文</font> |
| 2    | subsection    | <font color="#136ec2">\subsection</font>    | <font color="#136ec2">report</font>, <font color="#136ec2">book</font>类 |
| 3    | subsubsection | <font color="#136ec2">\subsubsection</font> | 默认不编号、不编目录                                         |
| 4    | paragraph     | <font color="#136ec2">\paragraph</font>     | 默认不编号、不编目录                                         |
| 5    | subparagraph  | <font color="#136ec2">\subparagraph</font>  | 默认不编号、不编目录                                         |

### 磁盘文件组织

小文档将所有内容写在同一个目录中。对比较大的文档，可以将文档分成多个文件，并划分文件目录结构：

- 主文档，给出文档框架结构
- 按内容章节划分不同的文件
- 使用单独的类文件和格式文件设置格式
- 用小文件隔离复杂的图表

相关命令：

- <font color="#136ec2">\documentclass</font>：读入文档类文件(.cls)
- <font color="#136ec2">\usepackage</font>：读入一个格式文件——宏包(.sty)
- <font color="#136ec2">\include</font>：分页，并读入章节文件(.tex)
- <font color="#136ec2">\input</font>：读入任意的文件

### 公式

#### 数学公式

- [在线 LaTeX 公式编辑器-编辑器 (latexlive.com)](https://www.latexlive.com/)

数学模式下字体、符号、间距与正文都不同，一切数学公式（包括单个符号$n$、$\pi$）都要在数学模式下输入。

- 行内（inline）公式：使用一对<font color="#136ec2">\$\$</font>来表示，如<font color="#136ec2">\$a+b=c\$</font>
- 显示（display）公式：
  - 简单的不编号公式用命令<font color="#136ec2">\\[</font>和<font color="#136ec2">\\]</font>表示。（不要使用双美元符号<font color="#136ec2">\$\$ \$\$</font>，会有细微的差异）
  - 基本的标号的公式用<font color="#136ec2">equation</font>环境
  - 更复杂的结构，使用<font color="#136ec2">amsmath</font>宏包提供专门的数学环境。（不要使用<font color="#136ec2">eqnarray</font>环境）

#### 数学结构

- 上标与下标：用^和_表示
- 上下划线与花括号：<font color="#136ec2">\overline</font>，<font color="#136ec2">\underline</font>，<font color="#136ec2">\overbrace</font>，<font color="#136ec2">\underbrace</font>
- 分式：<font color="#136ec2">\frac{分子}{分母}</font>：$\frac{分子}{分母}$
- 根式：<font color="#136ec2">\sqrt[次数]{根号下}</font>：$\sqrt[次数]{根号下}$
- 矩阵：使用<font color="#136ec2">amsmath</font>宏包提供的专门的矩阵环境<font color="#136ec2">matrix</font>，<font color="#136ec2">pmatrix</font>，<font color="#136ec2">bmatrix</font>等。特别复杂的矩阵（如带线条）使用<font color="#136ec2">array</font>环境作为表格画出。

#### 数学符号

- 数学字母$a,b,\alpha,\Delta$, 数学字体<font color="#136ec2">\mathbb</font>($\mathbb R$), <font color="#136ec2">\mathcal</font>($\mathcal P$)等
- 普通符号：如<font color="#136ec2">\infty</font>($\infty$), <font color="#136ec2">\angle</font>($\angle$)等
- 二元运算符：$a+b,a-b,a\oplus b$
- 二元关系符：$a=b,a\le b$
- 括号：$\left < a,b\right >$, 使用<font color="#136ec2">\left</font>, <font color="#136ec2">\right</font> <font color="red">放大</font>
- 标点：逗号、分号（<font color="#136ec2">\colon</font>）

不同的类型会决定不同的断行模式和不同的距离

#### amsmath 与 mathtools

- <font color="#136ec2">amsmath</font>是基本的数学工具包，在包含数学公式的文档中几乎无处不在。

- <font color="#136ec2">mathtools</font>则对 <font color="#136ec2">amsmath</font>做了一些补充和增强。

```latex
\documentclass{article}
\usepackage{amsmath}
\usepackage{mathtools}
\begin{document}
\begin{align*}
    2^5 &= (1+1)^5 \\
    &= \begin{multlined}[t]
    \binom50\cdot 1^5 + \binom51\cdot 1^4 \cdot 1
    + \binom52\cdot 1^3 \cdot 1^2 \\
    + \binom53\cdot 1^2 \cdot 1^3
    + \binom54\cdot 1 \cdot 1^4 + \binom55\cdot 1^5
    \end{multlined} \\
    &= \binom50 + \binom51 + \binom52 + \binom53
    + \binom54 + \binom55
    \end{align*}
\end{document}
```

### 基本规则

- ~~格式与内容分离~~不要在意细节
- 使用内容相关的命令与环境

```latex
It is \emph{important}。% 推荐
It is \textit{important}.  % 不推荐
```

两者在默认情况下效果一样，但是在不同模板效果不一定一样。

```latex
\caption{流程图}  % 推荐
\textbf{图 1: } 流程图  % 不推荐，不会自动编号 
```

### 使用宏包

- 作用：宏包将可重用的代码提取出来，相当于其他程序语言中的“库”。使用宏包可以用简单的接口实现非常复杂的功能，有些对于个人来说是“不可能的任务”。
- 问题：第三方宏包可能破坏 TEX 设计的“向前兼容性”；不同宏包之间如果出现兼容性问题更难解决。——使用宏包会将兼容性问题从 TEX 语言扩大到所有宏包代码。

现代$\LaTeX$文档离不开第三方宏包，但应该合理使用：

- 尽量不造轮子
- 尽量排除不使用的宏包
