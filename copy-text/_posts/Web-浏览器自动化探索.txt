> [!Note]
>
> 1. 安装基础环境，包括 Node.js、Playwright CLI 与 Chrome 浏览器。
> 2. 选择合适的 AI Agent 工具，并接入 Playwright 的 Skill 或工具链。
> 3. 向 AI 提供复杂任务，让其自主探索、执行并完成整个流程。
> 4. 将执行过程中的经验、规律与踩坑记录总结为可复用的 Skill。
> 5. 再次执行相同任务时，AI 可直接参考 Skill，显著降低推理成本与 Token 消耗，通常可降低约 10 倍。
> 6. 如果流程已经完全稳定，可进一步固化为脚本，实现脱离 AI 的纯自动化执行，将 Token 消耗降低至 0。
>
> 最终形成的模式是：**AI 负责探索与学习，脚本负责稳定执行。**

## OpenCLI

- [OpenCLI — Make Any Website Your CLI](https://opencli.info/)

> [!Note]
>
> | 维度         | OpenCLI                             | CLI-Anything                      |
> | ------------ | ----------------------------------- | --------------------------------- |
> | 核心思想     | 预先定义好的 CLI + Adapter 系统     | 用 LLM 动态生成 CLI / tool 接口   |
> | 本质         | 工程化自动化工具层                  | 生成式工具构建层                  |
> | 执行方式     | 固定命令 → 固定执行逻辑             | Prompt → LLM 生成命令/工具 → 执行 |
> | 稳定性       | 高（强确定性）                      | 中-低（依赖模型输出）             |
> | 可预测性     | 很强                                | 不稳定（可能变化）                |
> | 扩展能力     | 需要手写 adapter 扩展               | 可以自动扩展到未知系统            |
> | 是否依赖 LLM | 否或弱依赖                          | 强依赖                            |
> | 性能         | 快（几乎无推理成本）                | 慢（每次需要推理）                |
> | 成本         | 低                                  | 较高（LLM调用）                   |
> | 适用场景     | 生产自动化 / 数据抓取 / CI pipeline | AI agent 原型 / 探索未知系统      |
> | 调试难度     | 低（逻辑固定）                      | 高（输出不可控）                  |
> | 输出结构     | 固定 JSON / schema                  | 可能动态变化                      |
> | 工程风格     | 传统软件工程                        | AI-native agent 设计              |

```markdown
全部完成。以下是操作总结：
浏览器操作（已通过 opencli browser 完成）：
1. 打开 http://localhost:8080/steve/ → 已存在登录会话，直接进入 Dashboard
2. 点击导航栏 ABOUT (ref [8]) → 进入 /steve/manager/about 页面
3. 页面显示 SteVe 3.8.0、数据库版本、已登录的 Dashboard 内容、Endpoint 信息等
项目已创建： D:\Users\Documents\Study\Playwright\
- uv init → .venv Python 3.12 虚拟环境
- uv add playwright → Playwright 1.60.0
- uv run playwright install chromium → 已安装 Chromium 浏览器
脚本 main.py — 运行方式：
uv run python main.py
脚本逻辑：
1. 无头 Chromium（headless=False 可观察，slow_mo=300 看得清）
2. 导航到 /steve/，检测是否有登录页（找密码输入框）
3. 如有登录，填 admin / 1234 并提交
4. 点击 ABOUT 链接，等待 /about 加载
5. 截图保存为 about_page.png，打印标题和关键标题文本到控制台
6. 按回车退出浏览器
```

```python
from playwright.sync_api import sync_playwright


BASE_URL = "http://localhost:8080/steve/"


def run():
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=False, slow_mo=300)
        page = browser.new_page()

        page.goto(BASE_URL)

        if page.url.endswith("/signin") or page.locator("#username").count() > 0:
            page.locator("#username").fill("admin")
            page.locator("#password").fill("1234")
            page.locator("input[type=submit]").click()
            page.wait_for_url("**/manager/**", timeout=10000)

        page.locator("a[href*='/about']").first.click()
        page.wait_for_url("**/about")

        page.screenshot(path="about_page.png", full_page=True)

        title = page.title()
        version = page.locator("table").first.text_content()
        print(f"Title: {title}")
        print("Version table:", version.strip() if version else "")

        input("Press Enter to close browser...")
        browser.close()


if __name__ == "__main__":
    run()
```

```markdown
全部完成。以下是摘要：
浏览器操作 (通过 opencli):
1. 打开 http://localhost:8080/steve/ → 重定向到登录页
2. 在 #username 输入 admin，#password 输入 1234
3. 点击 "Sign In" → 成功登录到 /steve/manager/home?continue
4. 点击 ABOUT 链接 → 到达 /steve/manager/about
Python 环境与脚本:
- 使用 uv venv 在 D:\Users\Documents\Study\Selenium 下创建了虚拟环境
- 通过 uv pip install selenium 安装了 Selenium
- 脚本 steve_login.py 使用 headless Chrome (通过 Playwright 的 chrome-win64 二进制文件) 自动执行相同的步骤并打印 About 页面内容
运行方式:
uv run python steve_login.py
```

```python
import sys
import io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

BASE_URL = "http://localhost:8080/steve/"
USERNAME = "admin"
PASSWORD = "1234"

options = webdriver.ChromeOptions()
options.binary_location = r"C:\Users\XXX\AppData\Local\ms-playwright\chromium-1223\chrome-win64\chrome.exe"
options.add_argument("--headless=new")
driver = webdriver.Chrome(options=options)

try:
    wait = WebDriverWait(driver, 10)

    driver.get(BASE_URL)
    print(f"Opened: {driver.current_url}")

    username_input = wait.until(
        EC.presence_of_element_located((By.ID, "username"))
    )
    username_input.send_keys(USERNAME)
    print("Typed username")

    password_input = driver.find_element(By.ID, "password")
    password_input.send_keys(PASSWORD)
    print("Typed password")

    submit_btn = driver.find_element(By.CSS_SELECTOR, "input[type='submit']")
    submit_btn.click()
    print("Clicked Sign In")

    wait.until(
        EC.url_contains("/steve/manager/home")
    )
    print(f"Logged in, current URL: {driver.current_url}")

    about_link = wait.until(
        EC.element_to_be_clickable((By.CSS_SELECTOR, "a[href*='/steve/manager/about']"))
    )
    about_link.click()
    print("Clicked ABOUT link")

    wait.until(
        EC.url_contains("/steve/manager/about")
    )
    print(f"Reached About page: {driver.current_url}")

    page_text = driver.find_element(By.TAG_NAME, "body").text
    print(f"\n--- About Page Content ---\n{page_text}")

finally:
    driver.quit()
    print("\nBrowser closed.")

```
