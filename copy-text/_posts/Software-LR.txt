# 课程

## 【00-先导课】- 是什么让你的照片乌漆嘛黑不透亮？

- 如果没有 LR，使用 PS 的 **CameraRaw 滤镜** 也可以凑合着用
  - Adobe Camera Raw 支持多种相机，允许尽可能多的人轻松处理他们的原始图像
- **LUT**
  - Lookup Table（颜色查找表）
  - 可作为滤镜使用
  - 能快速转换色彩风格
  - 让每一个画面中的像素完成在色彩空间上的向量变化
  - 通俗点更像是一个滤镜
- **RGB**
  - xyz 轴标注着红色、绿色、蓝色的空间坐标

## 【01-理论课】- 从 RGB 和 CMYK 显色原理开始讲起

介绍颜色模型：

![jpg](1.1.jpg)

PS 制作一个三色盘：背景是**黑色**，红绿蓝三个圆形成**变亮**的混合更改

![jpg](1.2.jpg)

想让颜色变得更通透，如下图，更通透的蓝色其 CMYK 值中的 Y（黄）几乎为 0，因为蓝色的反色是黄色。

![jpg](1.3.jpg)

因此拖动曲线中的蓝色曲线，会使得画面变得

- 向下拖：更黄
- 向上拖：更蓝
- 左边向上拖，右边向下拖：蓝的更蓝，黄的更黄
- 左边向下拖，右边向上拖：蓝的不那么蓝，黄的不那么黄
## 【02-初体验】- 从第一次打开 Lr 开始介绍界面

- 修图离不开 PS，调色少不了 LR

- Lightroom 与 Lightroom Classic 的不同：

|                                    | Lightroom Classic | Lightroom              |
| ---------------------------------- | ----------------- | ---------------------- |
| 您更喜欢在哪里处理您的数字摄影工作 | 仅桌面            | 桌面、移动设备和 Web   |
| 原始文件位置                       | 本地硬盘          | 云                     |
| 文件备份                           | 不包含            | 自动                   |
| 易用性                             | 最全面            | 直观，简洁             |
| 整理和照片搜索                     | 手动关键字        | 自动添加标签和智能搜索 |

- Lightroom 支持 RAW 格式

> RAW 是一个**照片格式**的统称，就跟大家常见的 JPEG、PNG、TIFF 等一样，都是专指照片的档案格式。那为什么叫 RAW 呢？如同其中文字面意思「未经加工的、原始的」，它代表的是**未经过任何处理的影像资料**，也就是说 RAW 保留了所有感光元件上搜集的原始资讯，包含曝光、白平衡、色调、颜色、风格等等。

## 【05-实战篇】- Lr 风光大片基础调节（曲线）

- 曲线是一个二维坐标轴：

  - **纵坐标轴**表示**输出** $y$

  - **横坐标轴**表示**输入** $x$


- 默认的曲线就是一个 $y=x$ 的直线，表示没有任何处理

![jpg](5.1.jpg)

- 坏的曲线，黑死的更加黑死，过曝的更加过曝：

![jpg](5.2.jpg)

- 好的曲线应该是“牛奶型”的，较为光滑。

- 还可以修改 RGB 的单独通道。

![jpg](5.3.jpg)

## 【06-综合篇】- Lr 完成黑金效果实战

- 黑金视图的核心：去除所有的杂色，让画面中只有**黑色**和**金色**。
  - 偏向于橙红（加入一定的橙色来顶替金色）
  - 在黑色中加入浅的蓝色

- 黑金色调本身要强调**黑**，因此画面整体**曝光下降**是一个主流趋势
  - 色温 +11
  - 色调 -5
  - 曝光 -0.32
  - 对比度 +27
  - 高光 -83
  - 阴影 +40
  - 白色色阶 -78
  - 黑色色阶 -26（增强阴森感）
- 略微提高**去朦胧**和**纹理清晰度**，让画面的深邃感加强（不能太强，不然光斑过重）
- **鲜艳度**适当加强
  - 鲜艳度 +22
  - 饱和度 +5
- HSL / 颜色（控制画面中的颜色的整体分布和趋势）中，把不需要的颜色饱和度拉低
  - 绿、浅绿、蓝、紫、洋红饱和度降为 0
  - 色相：
    - 红色 +88
    - 橙色 -28
    - 黄色 -60
- 明度
  - 将画面颜色压暗（绿、浅绿、蓝、紫、洋红明度降为 0）
  - 黄色负责高光 -42
  - 橙色 +14
  - 红色 -83
- 颜色分级
  - 中间色 H29 S93L-47
  - 阴影加点蓝：H203 S46L-50
  - 高光加点黄：H44 S86L0
  - 混合 55
  - 平衡 +9
- 细节
  - 锐化数量 24
- 效果
  - 裁剪后暗角
- 曲线稍微拉高
