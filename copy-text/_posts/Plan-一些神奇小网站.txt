## 论文

### 检索

- [The latest in Machine Learning | Papers With Code](https://paperswithcode.com/)
  - 最喜欢的论文检索网站，首页就有最新的论文，很多论文都附有 GitHub 代码仓库

- [arXiv.org e-Print archive](https://arxiv.org/)
  - 可以找到很多还没没被期刊录用的论文，而且可以很方便地下载

- [dblp (uni-trier.de)](https://dblp.uni-trier.de/search)
  - 可以找到几乎所有期刊的目录

- [Sci-Hub: 将知识带给每个人](https://sci-hub.se/)
  - 听师兄说可以输入想要的文献的题目或者 DOI 来获得论文，但是好像比较新的文献查找不到

- [MDPI SciProfiles](https://sciprofiles.com/)
  - 这个网站可以把老师的名字输进去，看看师兄们都发了什么乱七八糟的论文，Electronics yyds！

- [全球学者库 (globalauthorid.com)](http://www.globalauthorid.com/)
  - 这个网站可以把老师的名字输进去，看看师兄们都发了什么乱七八糟的论文，Electronics yyds！

- [百度学术 - 保持学习的态度 (baidu.com)](https://xueshu.baidu.com/)
  - 没怎么试过，不过可以看到很多老师很久以前发的中文文献

- [Google Scholar](https://scholar.google.com/)
  - 可以把论文名字输进去，返回规范的 $\mathit{Bib}\TeX$ 格式

- [浙江图书馆 (zjlib.cn)](https://www.zjlib.cn/#searchs_1_div)
  - 可以进知网下一些中文论文，不知道现在好不好使

- [ChatPaper (chatwithpaper.org)](https://chatwithpaper.org/)
  - 辅助看论文的网站。

- [LetPub 编辑-SCI 论文润色机构、修改、翻译服务公司-英文论文修改机构](https://www.letpub.com.cn/)
  - 查看期刊水平的网站。

- 中国计算机学会推荐国际学术会议和期刊目录-2022
