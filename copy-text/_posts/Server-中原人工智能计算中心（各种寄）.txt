## PyCharm

### 配置

1. 先整一个专业版的 PyCharm，谢谢小迷糊！

![png](P1.png)

2. 在 Pycharm 中随便打开一个项目（就你了，yolov5-5.0 [ultralytics/yolov5 at v5.0 (github.com)](https://github.com/ultralytics/yolov5/tree/v5.0)），`Tools`-`Deployment`-`Configuration`:

![png](P2.png)

3. 点击 `SSH configuration` 的 `...` 以设置 SSH configuration

![png](P3.png)

4. 根据你创建的 Notebook 的参数 `ssh://ma-user@authoring-ssh.cncentral231.xckpjs.com:30376`，设置参数：

- `Host`: `authoring-ssh.cncentral231.xckpjs.com`
- `Username`: `ma-user`
- `Authentication type`: `Key Pair`
- `Private key file`: 之前存的 `KeyPair-9944.pem` 的地址

`Test Connection` 显示 `Successfully connected!` 即可。

![png](P4.png)

5. 在服务器中新建一个文件夹，用于存放项目文件，只有放在`work`文件夹里，下次再打开服务器时内容才不会丢失：

> /home/ma-user/work 目录下的数据会保存，其余目录下内容会被清理。如果需要保存开发环境，可以通过保存镜像的方式保留开发环境设置。

![png](P5.png)

6. 服务器中新建一个新的虚拟环境：`yolov5`：

```shell
conda create -n yolov5 python=3.7
source activate yolov5
which python
```

linux 环境下的 `which python` 可以返回当前虚拟环境下的解释器位置：`~/.conda/envs/yolov5/bin/python`

7. 设置解释器：Pycharm 下 File-Settings-Project: yolov5-5.0-Add Interpreter，选择 Existing 和对应的 SSH Server 地址：

![png](P6.png)

7. 设置好解释器和对应的服务器目录：

![png](P7.png)

8. 此时服务器里就会同步 yolov5 这个项目了，等待同步完成

![png](P8.png)

9. 在 `requirements.txt` 里，删除 `torch>=1.7.0` 和 `torchvision>=0.8.1` 这两行

![png](P9.png)

10. 在服务器中安装环境，这个服务器自带 1.8.1 版本的 pytorch，对应的是 0.9.1 的 torchvision，必须设定好版本，不然会寄：

```shell
cd /home/ma-user/work/yolov5-5.0/
pip install -r requirements.txt
pip install torchvision==0.9.1
```

11. 在自己的 Notebook 中选择 `更多`-`保存镜像`，以在下次启动服务器时，配置的环境不丢失。

![png](P11.png)

### 数据传输

《notebook 服务器数据准备》：主要用于将测试脚本、数据集、第三方依赖包等传输到 notebook 服务器

- 使用 linux 命令直接下载
  - 通过 wget，git 等命令直接下载
- 在本地已准备好的数据传输到 notebook 服务器
  - 传辅较小的脚本数据或数据集时可直接通过 mobaxterm 直接上传
  - 传输较大的文件（百 G 量级）时可通过 obs 传输（先从本地传输到 obs，再从 obs 传输到 notebook 服务器）

## 算法迁移实践（寄）

1. 进入迁移工具所在目录并执行迁移命令

```shell
cd /usr/local/Ascend/ascend-toolkit/latest/tools/x2mindspore
```

2. 设置好待迁移的工程 `/home/ma-user/work/yolov5-5.0/` 和迁移后的目录位置 `/home/ma-user/work/yolov5-5.0-mindspore`

![png](T2.png)

3. 开跑！

```shell
./run_x2mindspore.sh -i /home/ma-user/work/yolov5-5.0/ -o /home/ma-user/work/yolov5-5.0-mindspore -f pytorch
```

喜提错误：<font color="red">ModuleNotFoundError: No module named 'libcst'</font>，堵它：`pip install libcst`

4. 继续开跑！

![png](T4.png)

等等等……等到 `X2MindSpore run success, welcome to the next use.` 就可以 next use。

5. 把迁移好的项目下载到本地：

![png](T5.png)

6. 设置完解释器，然后修修补补……
