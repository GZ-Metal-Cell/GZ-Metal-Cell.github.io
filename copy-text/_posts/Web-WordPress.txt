# 正文

​	WordPress 本质上就是一个 PHP + MySQL 的网站程序。在不同平台上的安装方法：

| 系统    | 推荐环境包                                                   |
| ------- | ------------------------------------------------------------ |
| Windows | [XAMPP](https://www.apachefriends.org/index.html) 或 [WampServer](https://www.wampserver.com/en/) |
| macOS   | [MAMP](https://www.mamp.info/en/)                            |
| Linux   | 用系统包管理器安装 `apache2`、`php`、`mysql-server`          |

​	这里使用 XAMPP，安装到 `C:\xampp\htdocs\wordpress`（可选）。其会自带 Apache + MySQL + PHP。

​	下载 WordPress：[Download – WordPress.org](https://wordpress.org/download/)，得到 `wordpress-6.8.3.zip` ，解压到 Web 目录中（`C:\xampp\htdocs\wordpress`）。 

​	打开 `XAMPP` ，启动 `Apache` 和 `MySQL` 服务（`Actions` 下 `Start`），之后点击 `Admin` 打开 MySQL 的管理员界面。

> **其他相关功能**
>
> - **媒体库 (Media Library)**：统一管理上传的图片、音视频等文件。
> - **页面 (Pages)**：用于创建非博客性质的页面（如“关于我”、“联系”）。
> - **评论 (Comments)**：管理访客的评论，支持审核、回复、垃圾评论过滤。
> - **用户 (Users)**：可以添加多位作者或管理员。
> - **外观 (Appearance)**：切换主题、编辑菜单、挂件等。
> - **插件 (Plugins)**：安装 SEO、统计、Markdown、备份等插件。

​	选一个好看的外观，应用之。在网站页面 http://localhost/wordpress 上即可看到效果。

> [!Note]
>
> 如果你想让同一个局域网的其他电脑或手机也能访问你的 WordPress：
>
> 1. 在主机上打开命令行执行：
>
>    ```shell
>    ipconfig
>    ```
>
>    记下 IPv4 地址，比如 `192.168.1.5`；
>
> 2. 让别的设备在浏览器输入：http://192.168.1.5/wordpress
>
> 3. 如果打不开，检查：
>
>    - 防火墙是否允许 80 端口；
>    - Apache 是否已启动。
